# 복원

GitHub에서 새 폴더로 데이터 저장소를 clone하고 새 기기 설정에 해당 Vault를 지정합니다. 기존 Vault를 덮어쓰지 않습니다. 계정 연결은 새 기기에서 따로 준비합니다. `kg_rebuild_catalog` → `kg_validate` → 대표 키워드 검색 → 원문 SHA-256 확인을 수행합니다.

기록 ID·revision·원본·요약·목차·vocabulary가 복원의 기준입니다. 카탈로그만 손상됐으면 재생성할 수 있습니다. 기록 메타데이터를 파일명에서 추정해 만들지 않습니다.

.kg-runtime의 미완료 작업·미리보기·기기 영수증·잠금은 Git에서 복구되지 않습니다. push하지 않은 변경도 Git clone에 없습니다. Vault 전체 독립 사본을 백업한 경우에는 해당 실행 상태까지 보존할 수 있으며, 프로세스가 꺼진 상태에서 새 경로로 복원해 검증합니다. 예약 백업은 별도 사용자 요청 때 추가합니다.
