# 검증 상태

## 0.2.0: 직접 작성한 Inbox 자료

2026-10-14: MG Marketplace main의 공통 버전 관리와 검증 도구를 확인하고 플러그인 폴더 안의 소스를 기준으로 보강했다. 미등록 Inbox 파일의 재귀 탐색, 현재 경로에서 등록, 반복 등록 방지, 변경 원문의 이전 바이트 복원과 새 revision 보관을 추가했다. 기존 제목 기반 정리와 자기소개서 허브는 유지한다. Notion은 계속 미지원이다.

Node 24에서 전체 테스트 63개, TypeScript 검사, 번들 빌드와 배포 패키지 검사를 통과했다. 합성 검색 질문 40개도 모두 통과했다. 마켓플레이스 공통 관리 도구 테스트 9개를 통과했다.

회귀 테스트는 하위 폴더의 직접 작성 노트, 검색 누락 수, CRLF 원문 보존, 동일 경로 반복 등록, 분류 후 재등록, 제출 상태 변경과 반복 요청, 중단된 원문 복원, Git 이력 기반 복원, 복원 불가 보류, 제외 정책, Windows 대소문자 별칭, literal Git 파일명과 변경된 페이지 cursor를 포함한다. Obsidian에서 먼저 커밋과 푸시한 노트를 에이전트가 등록하고 분류한 후 다시 동기화하는 흐름도 로컬 Git 원격으로 검증했다. 다른 미등록 초안은 에이전트 동기화에 포함하지 않는다.

실제 MCP 실행 번들을 별도 세션 경로에서 SDK로 실행해 새 입력 스키마, 직접 등록, 중복 방지와 수정본 보존을 검증했다. 독립 리뷰에서 발견한 제외 정책 우회와 Git 패턴 확장, 반복 metadata 등록 문제를 실패 테스트로 재현한 뒤 수정했다. 스킬의 합성 호출 시나리오도 수정 전 누락과 수정 후 처리 흐름을 확인했다.

회귀 테스트는 실제 개인 Vault를 수정하지 않았다. 게시 후 마켓플레이스를 갱신했으며 Codex 설치 목록에서 0.2.0의 installed와 enabled 상태를 확인했다. 실제 설치 캐시의 MCP 번들도 별도 합성 Vault에서 직접 탐색, 현재 위치 등록, 반복 등록 방지, 이전 원문 보존과 구조 검사를 통과했다. 실행 중인 채팅의 기존 MCP 연결은 0.1.2를 유지하므로 새 버전을 사용하려면 Codex를 재실행하고 새 채팅을 연다. 최신 패키지의 Codex GUI와 Claude Code GUI 자연어 작업은 별도 확인이 필요하다. Claude CLI가 현재 환경에 없으므로 해당 CLI의 plugin validate는 실행하지 않았다. 로컬 매니페스트와 패키지 일관성 검사를 대신 수행했다.

MG Marketplace main 게시와 해당 커밋의 GitHub Actions 검사 성공을 확인했다. 기존 music-director와 application-coach의 설치 및 활성화 상태는 유지했다.

원본 복원은 완료된 로컬 저널 또는 해당 경로의 최근 Git 커밋 최대 100개에 한정한다. 원문을 확보하지 못하면 보류한다. `inbox_origin`과 `parent_revision`은 선택 메타데이터라 기존 기록을 다시 만들 필요는 없다. 자세한 흐름은 [직접 작성한 Inbox 자료](inbox.md)에 있다.

## 0.1.2 이전 검증 기록

2026-10-12: 제목 기반 원본·요약 파일명, 모든 essay 요약의 자기소개서 허브 자동 연결, 기본 그래프 필터, 성공 후 빈 Inbox 폴더 정리를 추가했습니다. UUID·revision·원본 해시를 유지합니다. 명시적 `migrate-readable` CLI로 기존 자료를 이전하며 수동 설명·코드 예시·원문 근거와 접근 제외 자료를 보존합니다.

전체 테스트 47/47, TypeScript 검사, 번들 빌드 및 패키지 검사를 통과했습니다. 새 회귀 테스트는 같은 제목 충돌, 기존 파일 보존, 실패 시 Inbox 유지, 다른 revision·메모 보존, 허브 확장, `%`·괄호 제목, 수동 목차·주제의 링크 갱신, 대소문자 경로, 제외 자료, 코드 예시, 외부 링크와 미작성 주제를 검증합니다. 독립 코드 리뷰의 Important 지적을 재현·수정했습니다. 실제 옵시디언 GUI의 그래프 재로드 여부는 파일·설정 검증과 별개입니다.

소스·합성 테스트를 배포본에 포함하여 MG Marketplace에서도 구현을 검토하고 재빌드할 수 있습니다. Vault 원본·기기 설정·자격 증명은 배포본에 포함하지 않습니다.

## 0.1.1 이전 검증 기록

작성일: 2026-10-12. Node 24.19.0, MCP SDK 1.32.1, Zod 4.6.5, YAML 2.9.1. Codex CLI 0.162.0-alpha.17.2 확인. 빌드·테스트 결과는 docs/progress.md에 기록합니다.

합성 자료로 원본 보존·근거·검색·로컬 Git 원격·복원을 시험합니다. 전체 39개 테스트와 검색 질문 40개를 통과했습니다. Windows Git clone의 줄바꿈·번들 보존 시험을 포함합니다. Private 데이터 원격은 사용자 요청으로 Etchroot/Etchroot-knowledge-base에 생성하고 빈 시스템 구조를 push했습니다. 실제 개인 원본 등록과 Notion page는 아직 없습니다. 두 앱의 실제 GUI 수용 시험은 별도이며 SDK 클라이언트 시험과 동일하다고 주장하지 않습니다.

최종 독립 리뷰의 10개 지적은 재현 테스트 11개를 추가해 수정했습니다. 원본·주제 편집의 snapshot 해시, 단일 Private push 대상, 커밋에 포함된 작업만 성공 처리, 미승인 로컬 커밋 차단, 상대 링크, 종료한 writer 복구, 수동 추출 검색, 배포본 bridge, 깨끗한 Vault의 fast-forward, 동기화 전 구조 검증을 포함합니다. 호스트 manifest 공식 JSON Schema 검증은 수행하지 않았으며 로컬 일관성 검사와 Codex 실제 설치 결과만 확인했습니다.

MG Marketplace 등록 파일과 패키지를 로컬에서 준비합니다. 원격 main에 push한 뒤에야 사용자의 원격 marketplace 업데이트에 나타납니다. 현재 원격 게시 여부는 구현 기록을 확인하세요.

업데이트 → 신규 플러그인 설치 → 새 채팅 → setup → status/validate 순서입니다. 이후 버전은 설치한 플러그인의 update/reload도 확인합니다. Vault·config·credentials는 패키지에 포함하지 않습니다.
