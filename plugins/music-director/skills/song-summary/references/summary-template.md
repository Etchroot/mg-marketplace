# 작품 정리 양식과 적용 기준

## 기존 문서에서 가져온 구성

다섯 프로젝트 문서의 공통 항목을 정리한 양식이다. 과거 장르·템포·취향은 기본값이 아니다.

| 기존 사례 | 양식에 반영한 점 |
| --- | --- |
| Autumn on Me | 짧은 주제 소개, 계절·감정 흐름, 구간별 확정 가사, 가창 방향 |
| 가을 다 가잖아 | 화자의 전체 태도를 요약한 소개, 주 장르와 결합 요소 구분, 제작 파일 버전 |
| 나는 가을에도 패딩을 입어요 | 작품 정보, 기획값 표시, 최종 프롬프트 본문, 폐기한 초기 설정 구분 |
| 경계의 너머 | 연주곡 전환, 악기와 구간 대비, 보컬 초안의 분리, 커버 콘셉트 |
| 청량과 설렘 그리고 롯데몰 | 별도 제출용 제목·소개, 글자 수, 파일 규격, AI 도구·구독제 |

아래 구조는 기본 출발점이다. 기존 파일의 유용한 내용과 사용자 확정 문구를 보존하며 필요한 항목만 수록한다. 중괄호는 작성 지침이며 완성 문서에 남기지 않는다.

## 공통 본문

```markdown
# {작품명} — 작품 정리

## 작품 정보

- 작품명: {확정 제목 또는 미정}
- 형식: {보컬곡 / 연주곡}
- 상태: {사용자 확정 / 작업 중}
- 장르·스타일: {곡별 설정 또는 분석 제안임을 표시}
- 제작 도구: {확인된 경우}
- 템포·박자: {기획값 또는 측정값 + 근거}
- 길이: {목표 / 사용자 확인 / 실측 중 구분}
- 최종 음원: {채택이 확인된 파일 링크; 미확정이면 명시}

## 곡 소개

{주제·화자의 태도 또는 연주곡의 인상과 음악적 특징을 짧게 소개}

## 음악 방향과 구성

{훅·악기·리듬·구간 대비·감정 흐름·도입과 엔딩 중 중요한 특징}
{구간 순서; 시간표가 있으면 목표인지 실측인지 표시}

## 제작 파일

| 용도 | 파일 | 상태·근거 |
| --- | --- | --- |
| {음원 / 가사 프롬프트 / 스타일 / 제외 / 커버 등} | {존재 확인한 링크} | {채택본 / 후보 / 기존 기록} |
```

## 보컬곡 추가 모듈

- `확정 가사`: 구간 제목과 원문 줄바꿈을 그대로 유지한다. 간주 등은 '가사 없음'으로 짧게 표시할 수 있다. 아직 확정되지 않았다면 '가사 초안'으로 이름을 바꾼다.
- `가창 방향`: 선택된 보컬·프레이징·쉼의 특징만 적는다. 지정된 연령·음색은 제작 목표이며 실제 보컬의 신원이나 나이로 쓰지 않는다.
- 프롬프트 지시문은 가사 원문과 별도이며, 구간별 시간을 분석하지 않았다면 제목에 임의 실측 시간을 붙이지 않는다.

## 연주곡 추가 모듈

- 가사와 보컬 정보 없이 리드 악기·훅·편곡 대비를 기록한다.
- 가사 있는 곡을 검토하다 연주곡으로 전환한 경우, 최종 채택 모드와 채택 파일을 먼저 표시한다. 영어 보컬 훅·보컬 먼저 진입 같은 폐기 설정을 최종 설명으로 복사하지 않는다.
- 스토리 기획을 콘셉트로 유지할 수 있으나 화자의 사건을 실제 연주곡이 전달하는 사실로 단정하지 않는다.

## 선택 모듈

### 레퍼런스

작품명·아티스트·기법·분석 기록 링크를 적는다. 참고한 곡의 크레딧을 새 작품의 크레딧으로 옮기지 않는다. 레퍼런스를 조사한 적이 없으면 정리만을 위해 조사를 확장하지 않는다.

### 커버

존재하는 이미지 링크, 확인된 콘셉트, 제목 표기 여부를 기록한다. 크기·포맷은 확인된 경우만 수록한다. 생성하지 않은 이미지를 완성 파일처럼 링크하지 않는다.

### 공모전 제출 정보

작품 정리 전체와 별개로 그대로 복사할 수 있는 제목·소개를 둔다. 일반 소개와 제출 소개가 같을 필요는 없다.

| 항목 | 기록 기준 |
| --- | --- |
| 제출 제목·소개 | 사용자가 확정한 정확한 본문 |
| 글자 수·상한 | 공백·문장부호 포함 실제 계산, 코드포인트/UTF-16 등 방식 명시 |
| 제출 파일 | 확인된 채택 파일 경로 |
| 형식·샘플레이트·비트 심도·채널·길이·용량 | 실측 또는 이전 기록 여부와 검사 방법 |
| AI 서비스·구독제·생성 시점 증빙 | 확인된 정보만; 구독제를 생성 당시 정보로 자동 간주하지 않음 |
| 공고의 요구 규격 | 제공 자료 또는 확인한 공식 출처·확인일 |
| 규격 점검 | 확인된 것과 해석·미확인 사항을 구분; 제출 자체는 수행하지 않음 |

### 이전 작업 기록·미확인 사항

최종 선택을 혼동하게 하는 폐기 방향만 짧게 설명한다. 상세 수정 일지는 별도 파일로 연결한다. 미확인 음원 파일·실제 길이 등 다음에 필요한 핵심만 남긴다.
