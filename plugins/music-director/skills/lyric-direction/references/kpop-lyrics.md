# K-pop 가사 작성 지침

K-pop으로 정한 곡의 가사와 프레이징을 작성할 때만 참고한다. 시대, 콘셉트와 사용자 요청에 따라 선택하며 다른 장르의 기본 작사법으로 확대하지 않는다.

## 표현과 훅

- 먼저 누가 누구에게 무엇을 말하거나 함께 하려는지 정한다. 벌스는 실제 말, 행동이나 태도로 구체화하되 소품 나열이나 사건 설명만으로 채우지 않는다.
- 후렴은 기억할 핵심 말과 발음의 쾌감을 중심으로 쓴다. 초대나 자신감을 직접 말해도 되며 모든 줄을 시적 비유로 꾸미지 않는다. 반복 훅과 새로운 내용을 주는 벌스의 역할을 나눈다.
- 비유는 화자의 태도와 장면 안에서 연결한다. 추상적인 주어에 움직임만 붙인 범용 문장이나 근거 없는 낙관으로 희망을 대신하지 않는다. 반대로 비유를 전부 금지하거나 교훈, 위로와 부정적 과거를 억지로 넣는 공식도 피한다.
- 한국어와 영어의 비율, 어휘의 난도는 곡별로 정한다. 발음, 강세, 라임과 의미를 함께 살피며 한영 교대나 영어 삽입을 의무화하지 않는다.
- 참고곡에서는 발화 방식, 훅의 반복과 장면 연결 원리를 추출한다. 가사와 고유한 표현은 복사하지 않으며 차트 성적을 특정 작사법의 효과로 단정하지 않는다.

## 반주 음원이 있는 경우

- 길이와 BPM만으로 가사 줄 수를 정하지 않는다. 사용 가능한 환경이면 Beat This!로 박과 마디 첫 박 후보를, librosa로 타격 시작점과 강도, 반복과 변화 후보를 함께 분석한다. 두 도구는 별도 설치가 필요한 선택적 분석 도구이며 이 플러그인에 내장된 청취 기능이 아니다.
- 검출값, 사용자 청취 관찰과 편곡 제안을 구분한다. 마디 첫 박의 어긋남과 누락을 확인하고 필요하면 클릭 가이드로 비교한다. 변화 점수를 벌스나 후렴 경계로 자동 확정하거나 분석 수치만으로 들었다고 말하지 않는다. 분석 불가 시 임의 시간표를 실측값처럼 제시하지 않는다.
- 사용자가 8마디 단위를 느꼈다면 해당 곡의 파트 후보로 검토한다. 실제 반복과 전환을 확인해 2마디, 4마디 프레이즈로 나누며 모든 K-pop 곡을 8마디 구조로 강제하지 않는다.
- 문장을 음절 수에 억지로 맞추기 전에 구간별 의미와 핵심 말을 정한다. 실제 반주 위에서 보컬 시작 위치, 당김음, 끊는 곳, 지속음과 호흡을 설계한 뒤 발음을 배치한다. 악기의 모든 타격에 음절을 붙이지 않는다.
- 같은 멜로디가 반복되는 대응 줄끼리 음절 수와 발음 길이, 강세를 가깝게 맞춘다. 전체 가사를 같은 글자 수로 통일하지 않으며 받침, 모음 지속과 실제 가창 가능성을 함께 검토한다. 반주 분석만으로 보컬 선율이나 음절 배치가 확정되지는 않는다.
- 단조로운 반주에는 구간별 보컬 음역, 말하듯 부르는 리듬과 선율, 유니슨과 겹침으로 대비를 설계한다. 전주, 간주, 후주와 무보컬 허용 범위는 곡별 요청을 따른다. 분석과 가사 적합성을 확인하기 전 효과가 검증됐다고 기록하지 않는다.
