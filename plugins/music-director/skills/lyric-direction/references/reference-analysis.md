# 레퍼런스 조사·분석 파일

## 조사 절차

1. 제목·아티스트와 버전을 식별한다. 공식 아티스트/레이블/음반 크레딧/작곡가 기록을 우선한다. 보조 출처는 종류를 표시한다.
2. 원곡의 공연자, 보컬, 작사, 작곡, 편곡을 구분한다. 원곡 작곡과 커버 편곡 크레딧을 섞지 않는다.
3. 링크가 열려도 오디오를 실제로 들을 수 있는지는 별도 확인한다. 검색 도구만으로 세션별 악기나 도입의 초 단위를 확정하지 않는다.
4. 확인 가능한 음악 특성은 관찰 근거를 함께 적는다. 장르 해석과 사용자 느낌도 가치가 있지만 사실과 구분한다.
5. 파일을 저장하고 경로를 알려준 뒤, 반주 우선/가사 우선 선택을 묻는다. 분석으로 파악된 장점과 새 곡의 방향은 사용자가 수정할 수 있다.

불일치 처리:
- BPM 두 배/절반 표기, 원곡과 커버·라이브·TV 편집의 차이부터 확인한다.
- 신뢰 가능한 합의가 없으면 값을 병기하고 정확값을 미확인으로 둔다.
- 청취와 출처가 없는 타임스탬프는 만들지 않는다.
- 원곡 길이를 새 곡 길이로 자동 채택하지 않는다.

## 파일에 담을 항목

- 곡 식별: 제목, 아티스트/보컬, 버전, 링크, 확인일
- 크레딧: 작사/작곡/편곡, 발매·타이업, 항목별 출처
- 청취 상태: 실제 청취/사용자 오디오 관찰/사용자 설명만/메타데이터 조사만
- 근거 표: 항목 | 내용 | 출처 또는 근거 | 확정/추정/미확인
- 음악 특성: 장르 분류, 템포·박자, 리듬 분할·체감 속도, 보컬, 악기·편곡
- 구조 표: 구간 | 음악 역할 | 감정 고저 | 훅 재사용 | 확인 수준
- 도입·엔딩: 진입 순서, 강약, 잔향, 전환 방식
- 새 곡에 가져올 기법과 사용자가 특히 좋아한 요소
- 적용하지 않을 구체적 원곡 요소(가사·멜로디·음성 등)
- 미확인 정보와 후속 선택: 반주 우선/가사 우선

## 도구가 제한된 경우의 전달 예시

“공식 페이지에서 제목·보컬·크레딧은 확인했지만 이 환경에서 오디오는 재생하지 못했습니다. 구간 구조와 음색은 사용자 설명에 근거한 잠정 분석으로 기록했어요. 분석 파일을 바탕으로 반주부터 만들까요, 가사부터 정할까요?”

이는 상황에 따른 예시다. 실제로 들었다면 청취 관찰을 기록하고, 아직 크레딧도 확인하지 못했다면 확인했다고 말하지 않는다.
