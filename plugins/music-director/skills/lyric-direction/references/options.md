# 곡별 선택 설정

기본값은 이전 곡에서 복사하지 않는다. 이미 선택한 항목을 존중하고, 아직 결정할 필요 없는 항목은 비워 둔다.
아래 항목은 양식이지 필수 질문 목록이 아니다.

| 설정 | 선택 예시 / 기록 방법 |
| --- | --- |
| 목적 | 개인 곡, 공모전, 매장 BGM, 애니메이션 오프닝 분위기 등 |
| 진행 순서 | 반주 우선 / 가사 우선 / 기존 곡 수정 |
| 장르·시대 | 자유 입력. 분류 근거 또는 제안 여부 표시 |
| 템포 | 목표 BPM, 박자, 체감 박자(half-time 등)와 음표 밀도 |
| 길이 | 목표 길이 / 실제 생성 길이 / 미측정 상태 |
| 악기 | 주도 악기, 반주 악기, 음역·어택·잔향 |
| 보컬 | 성별·음역·나이 이미지·톤·호흡·강세·고음 지원 정도, 보컬 없음 |
| 언어 | 한국어·영어·혼합·기타. 혼합 비율과 발음·강세 |
| 내용 | 화자, 시점, 관계, 장면, 비유, 계절, 정서 변화 |
| 문장 밀도 | 서술형 / 이미지·조각 중심 / 균형. 종결 어미와 라임 선택 |
| 구조 | 순서, 반복 구간, 가사 없는 구간, 구간 대비 |
| 코러스 그룹 | 각 숫자가 한 그룹의 줄 수인지 기록. 예: [4,4], [3,3,3], [1,2,2,2,1] |
| 훅 | 보컬/악기, 길이, 반복 횟수, 재등장 위치 |
| 도입 | 악기 우선 / 보컬 우선 / 동시, 반주 지연, 시작 에너지·음역, 프레이즈 분리 |
| 쉼 | 없음 / 호흡 / 한 박 / 악기 응답. 시간·박 수는 필요할 때만 |
| 엔딩 | 완결 화음 / 페이드 / 여운 / 짧은 변주 / 콜드 엔딩 등 |
| 시간 지시 | 구간만 / 마디 기반 / 시간표. 60×박수×마디/BPM으로 설계하되 실제 시간과 구분 |
| 스타일 제한 | UI 상한, 실제 측정 방식, 여유 예산 |
| Suno UI | 현재 모델, 길이·보컬·스타일 영향 등 사용자가 지정한 값 |
| 제외 스타일 | 선택 방향에 반하는 요소만 |
| 출력 | 대화/파일, 부분 교체/전체, 경로·파일명, 버전 관리 |

브리프에는 “확정 / 제안 / 미정 / 사용자 관찰 / 실제 확인” 상태를 적는다.
‘코러스 1/2/2/2/1’이라면 실제 8줄이며 그룹 경계를 표시한다. 모든 곡에 이 묶음을 강제하지 않는다.
보컬 연령은 이미지 지시다. 정확한 나이·실존 인물 목소리 재현을 보장하지 않는다.
마디 기반 시간 계산은 일정한 템포와 박자를 가정한 설계값이다. 픽업, 자유 템포, 길게 잡은 음, 실제 생성 구간 길이는 별도 확인한다.
