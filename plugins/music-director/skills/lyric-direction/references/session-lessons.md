# 작업 기록에서 추출한 관찰과 수정 후보

이 자료는 한 사용자의 여러 곡에서 나온 피드백을 정리한 것이다. 모델·설정·실제 음원이 모두 보존되거나 검증된 실험이 아니므로 Suno의 일반적 동작 원리나 효과 보장으로 취급하지 않는다. 인용된 짧은 문구는 문제 유형 설명용이며 새 가사에 복사할 템플릿이 아니다.

| 기록의 관찰 | 수정 후보와 이유 | 적용 한계 |
| --- | --- | --- |
| 리듬 중심 곡에서 모든 문장을 완결하고 원인·결과를 설명하니 소설처럼 느껴짐 | 장면·음절·라임·쉼을 중심으로 줄이고 구절 경계 명시 | 서술형 발라드에는 완결 문장이 어울릴 수 있음 |
| 빙음 효과 지시가 물 붓기나 날카로운 타격처럼 생성됨 | 의미를 단순화하거나 효과음을 별도 작업으로 분리 | 효과음 생성·검색·라이선스 처리는 이 스킬의 자동 기능이 아님 |
| 특정 가을 연애곡에서 붕어빵·목도리·핫팩이 겨울 이미지로 지적됨 | 해당 장면의 계절·기온·상황에 맞는 소품 선택 | 실제 지역·시기·의도에 따라 가을에도 가능; 전역 금지 아님 |
| 간주 전에 가사가 나오거나 보컬 도입이 지켜지지 않음 | 첫 소리, 반주 진입 순서, 무가사 구간을 가사·스타일에서 일치시킴 | MUST/초 단위 지시가 정확한 타이밍을 보장하지 않음 |
| 긴 전주·반복 지시에도 다른 길이로 생성됨 | 현재 결과를 확인하고 지시 밀도·구조를 조정; 사용자 편집 대안 제시 | 길이 상세설정도 실제 구간 배치를 보장하지 않음 |
| 두 줄로 나눈 영어 훅 사이에 간주가 삽입됨 | 두 줄 표기와 별개로 한 프레이즈·중간 악기 응답 없음 명시 | 줄바꿈이 항상 간주를 유발한다는 증거는 아님 |
| 여리고 몽환적인 보컬 설정이 도입에서도 속삭임으로 나타남 | 도입의 음역·어택·지지된 발성을 따로 지정하고 벌스와 대비 | 특정 가수의 이름이나 보컬 나이가 같은 결과를 보장하지 않음 |
| 넓은 매장에서 플루트가 날카롭게 느껴지고 다른 악기가 동요처럼 들림 | 음역·어택·배음·배치와 장르 조합을 수정 | 플루트/실로폰 자체가 부적절하다는 일반 규칙 아님 |
| 전통적·시대 불명확한 발라드 문구가 옛 가요·트로트처럼 들림 | 원하는 시대·발성·비브라토·드럼 형태를 구체화 | traditional/timeless 등이 항상 트로트를 유발한다는 인과 증거 없음 |
| BPM을 올려도 부드러운 지속음 때문에 느리게 들림 | 드럼 악센트, 짧은 음, 분할, 쉼을 검토 | 빠른 BPM, 스윙 금지 또는 정박을 기본값으로 고정하지 않음 |
| 엔딩 변주 후에도 피아노 아르페지오가 추가됨 | 기존 여운/후주 지시 제거 후 선택된 콜드 엔딩을 필드 간 통합 | 콜드 엔딩은 해당 곡에서 사용자가 만족한 방법이며 보편적 선호 아님 |
| 코러스 4/4 → 3/3/3 → 1/2/2/2/1로 변화 | 실제 반주의 프레이즈와 가사 줄 수를 맞춤 | 특정 그룹 구성이 더 우수하다는 보편적 근거 없음 |
| 스타일가 1,000자 이하라는 안내가 실제로 틀림 | 정확한 붙여 넣을 문자열의 길이를 도구로 계산하고 수정 후 재계산 | 영어 글자 수 추산이나 토큰 수로 대체하지 않음 |
| 바뀐 가사를 정리 파일에서 다시 찾을 필요가 생김 | 확정본 위치·버전·수정 이유를 기록하고 최신본을 연결 | 모든 요청에 다수의 파일을 만들 필요는 없음 |

## 수정 로그 양식

- 대상 프로젝트·버전·날짜
- 사용자 관찰: 실제 사용자가 말한 결과. 음원 미청취이면 명시
- 유지할 요소 / 변경할 요소
- 원인 가설: 확정 인과와 분리
- 변경한 가사·스타일·제외 항목
- 생성 결과: 사용자 피드백 / 직접 청취 / 아직 결과 없음
- 채택 여부와 다음 수정
- 적용 범위: 해당 곡만 / 다른 곡에서 검토할 후보

사용자 피드백이 없는 새 버전의 효과를 성공으로 기록하지 않는다.
