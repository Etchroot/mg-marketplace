# 공개 자소서·경험 사례

사용자가 제공한 자소서 두 편을 정리하고 공개 GitHub 업로드를 요청해 보관한 자료입니다. 다른 사용자의 실제 경험이나 범용 답변 템플릿으로 자동 채택하지 않습니다.

| 사례 | 자소서 본문 | 경험 정리 | 근거·글자 수 |
| --- | --- | --- | --- |
| 가장 어려운 문제를 해결한 경험 — 잔향 | [본문](cases/janhyang/answer.md) | [다섯 항목](cases/janhyang/experience.md) | [메타데이터](cases/janhyang/metadata.json) |
| 끝까지 몰입한 경험 — GIDDA | [본문](cases/gidda/answer.md) | [다섯 항목](cases/gidda/experience.md) | [메타데이터](cases/gidda/metadata.json) |

## 본문 보존

- [잔향 원본](sources/janhyang.md)과 [GIDDA 원본](sources/gidda.md)은 제공 파일을 바이트 단위로 그대로 복사했습니다.
- answer.md는 원문의 완성 자소서 부분을 추출했습니다. 인용 블록 표기와 줄바꿈 형식만 정리했고, 문구·문장 순서·문단·강조는 바꾸지 않았습니다.
- 원본의 `글자 수: 0자`는 내보내기 자료에 그대로 남아 있습니다. 별도 metadata.json에는 본문을 실제 계산한 값을 기록했습니다.
- 경험 자료는 상황 / 문제에 대한 판단 / 행동 / 결과 / 경험으로 드러난 가치관으로 나눴습니다. 원문 경험 정리에서 옮겼으며 새로운 성과나 가치관을 추가하지 않았습니다.

## 출처 상태

두 문서에는 `2025년 9월 모집 / 2026 카카오그룹 신입크루 공채 / 카카오 Tech 직군(Tech_Tech 공통)`이라는 표기와 문항이 있습니다. 이 정보는 원문 표기로 보존했지만 정확한 공고 게시일과 원문 링크는 제공되지 않았고 독립적으로 검증하지 않았습니다. 따라서 이 자료는 **사용자 제공 자소서 사례**이며, 플러그인의 최근 2년 검증 질문 배치에는 포함하지 않았습니다.

이 자료는 원 인터뷰 전체가 아니라 완성된 내보내기 문서입니다. 경험의 모든 사실을 독립 검증했다거나 실제 대화 종료 과정을 재현한 자료라고 표시하지 않습니다.

## 재사용

[index.json](index.json)은 두 사례의 경로 목록입니다. 각 폴더의 experience.json은 다섯 항목을 보존한 공개 사례 스냅샷이며, 로컬 catalog.json에 자동 등록한 실행 데이터가 아닙니다. 원본·답변 SHA-256은 메타데이터에서 확인할 수 있습니다.

새로운 인터뷰와 답변 구체화에는 [experience-to-answer 스킬](../../plugins/application-coach/skills/experience-to-answer/SKILL.md)을 사용합니다. 사례의 구체적인 행동과 성과를 다른 사람에게 복사하지 말고, 다섯 항목이 어떻게 연결되는지를 참고하세요.
